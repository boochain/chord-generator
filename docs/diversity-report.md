# 多样性报告：v3.1（改造前）→ v4.0（改造后）

用户反馈：“同质化太严重，生成的都差不多”。本报告先量化问题，再给出原因和 v4 的改造，最后用同一工具复测。

## 1. 测量方法

工具：`node tools/diversity.js 500 docs/diversity-after.json`（改造前数据：`docs/diversity-before.json` / `.txt`）。

- 每个非固定曲式风格（73 个，布鲁斯等 12 小节固定曲式除外）各生成 **500 首**，固定 8 小节、每小节 1 个和弦，种子确定、可复现。
- 进行比较的是“罗马数字骨架”（去掉七/九/挂留等性质与转位），所以只换和弦性质不算新进行。
- 指标：
  - **唯一进行比例**：不同骨架数 / 生成数。
  - **4-gram**：不同的连续 4 和弦片段数。
  - **熵 H**：和弦分布熵（比特）。
  - **前 10 占比**：出现最多的 10 条进行占全部的比例。
  - **编辑距离**：随机两两比较的归一化 Levenshtein 距离。
  - **排列 / 伴奏型种类**：前 4 个和弦的排列形状签名种类；每风格出现的伴奏型种类。
  - **参数敏感度**：同一风格只改情绪 / 复杂度 / 拍号 / 调式时，两组输出骨架集合的重叠度，**越低说明参数影响越大**。
  - **连续点击**：不指定种子连续生成 150 次，统计与上一次相同、与最近 5 次相同的比例和唯一比例。
  - **扩展**：歌曲扩展中不同段落骨架互不相同的比例、多次扩展结果的唯一比例。

## 3. 原因诊断（v3.1）

1. **语料太小**：每个风格大类只有 5–7 条进行。子风格的 `tpl`（`ownTpl`）有排他优先权，很多子风格实际上只在 2 条模板里选。
2. **80% 的选择来自主池**，马尔可夫补充只占 20%，而且只在“模板不合规”时才触发。
3. **8 小节 = 4 和弦模板循环两次（AA）**：一首歌只做了一次选择，而一次选择最多只有几种可能。
4. **情绪不参与选模板**，只影响借用/副属概率和速度，所以情绪重叠度 0.996。
5. **拍号对和声没有任何影响**（重叠度 1.0）。
6. **生成之间没有记忆**：连续点击 37% 的概率与最近 5 次之一相同。
7. **每个风格固定一种伴奏型、一种密集排列**。校验器的“上方声部跨度 ≤ 八度”实际上禁止了开放排列。
8. **模态模板写法错误**：弗拉门戈的 `bVII` 在弗里几亚调式中应为小三和弦 `bvii`，大写写法被判为不合规借用而全部过滤，最终只剩 `i iv V i` 一条；洛克里亚调式下的金属、恐怖模板也几乎全被过滤。
9. **歌曲扩展**：每段主歌都原样循环种子。

## 4. v4 的改造（架构详见 `docs/architecture.md`）

- **和声引擎重写为分层规划**：曲式（AABA / ABAB / ABAC / AA'BA' / ABCD …）→ 乐句 → 终止目标。
- **每个乐句约 30 个候选**，来自：大幅扩充的风格语料（约 400 条，带出处）、子风格进行、旋转、拼接（接缝须在语料中出现过）、功能代理替换、风格可变阶（3/2/1/0）马尔可夫游走、经过/辅助和弦插入（和声节奏变化）。
- **软约束打分 + softmax 采样**（τ = 0.7）：打分包括语言模型概率、情绪特征、拍号特征、复杂度匹配、重复惩罚、本曲新颖度和跨点击新颖度。
- **终止式多样化**：正格、ii–V–I、IV–V–I、变格、小调变格、后门、♭VI–♭VII–I、重属、♭VII→i、安达卢西亚、iv–V–i、调式终止；中间句可用半终止或阻碍进行；A' 变奏句。
- **反重复记忆**：每风格最近 48 个乐句，只对不指定种子的生成生效，指定种子仍可复现。
- **编配多样化**：
  - 每首歌抽取伴奏型（风格本型 + 近亲型）、排列（密集 / 开放 drop-2·展开 / 混合，按风格加权）和旋律轮廓（拱形 / 倒拱形 / 上行 / 下行 / 波浪 / 自由）。
  - 校验规则放宽为 SATB 习惯：相邻声部 ≤ 八度、总跨度 ≤ 19 半音。
- **设置多样化**：默认小节数加入 12 小节；支持多拍号的风格少量使用非 4/4。
- **弱风格语料**：修正模态写法，并为弗拉门戈、死亡金属、恐怖、雷鬼顿、流行朋克、探戈、斯卡、萨尔萨、爵士说唱、舞厅雷鬼、P-Funk、奇幻补充 10–20 条进行。洛克里亚 / 弗里几亚用级数写法，保证在调式内合法。
- **歌曲扩展**：第二段主歌必定变奏（保留前半句种子动机，后半句做代理替换或重新配和声）；导歌、桥段、副歌延伸部分与已用乐句互相避让。
- **重新生成**会传递情绪和拍号，并以当前歌曲的乐句作为记忆。
- **修复**：Lo-fi 伴奏型缺少 `break`（误落入 boom-bap）；圆舞曲型在短时值和弦上不发声。

## 5. 质量保证

- 乐理校验 100% 通过（`npm test` 中 2500 首随机生成 + 扩展 + 重新生成），平均尝试次数约 1.01。
- 原有音乐性回归阈值保持不变：调内和弦 ≥ 85%、4/4 ≥ 90%、全部终止于主和弦、乐句重复 ≥ 70%、旋律级进 ≥ 80%。
- 新增 `test/diversity.test.js`（纳入 `npm test`），阈值留有余量：
  - 平均唯一 ≥ 75%（N = 60）；前 10 占比 ≤ 40%；最差风格 ≥ 55%。
  - 原最弱五个风格 ≥ 75%。
  - 连续点击：不与上一次重复，最近 5 次内重复 ≤ 3，唯一 ≥ 70%。
  - 情绪 / 复杂度重叠度 ≤ 0.7。
  - 编配：伴奏型 ≥ 8 种、三种排列都出现、旋律轮廓 ≥ 5 种、开放排列占 10%–60%。
  - 扩展：唯一 ≥ 90%，第二段主歌变奏 ≥ 80%。
